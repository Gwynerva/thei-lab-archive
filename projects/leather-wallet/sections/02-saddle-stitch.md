Started stitching tonight! Two needles, one long waxed thread, and both needles go through every hole from opposite sides. It's slow. It's *so* slow. About a centimetre a minute when I'm concentrating, half that when the telly's on.

- [x] card pockets, left
- [x] card pockets, right (in Copenhagen!)
- [x] coin pocket, twice, because the first one was inside out
- [x] the long seam round the outside
- [ ] burnish the edges properly (never)

The trick, the man in the video says, is to pull every stitch with the same tension and take the thread the same way round the needle each time, so the stitches all lean the same way. Mine lean the same way for about three centimetres and then have opinions.

Finished on Saturday the 4th, burnished the edges with a bit of canvas and some spit, rubbed it with beeswax, and moved everything over from the freezer bag I'd been using as a wallet for a month. ~~Never again.~~ Already planning a card holder.
