Six months of evenings after work, and most Sundays, at the kitchen table in Leith with Callum cooking around me. What 1.0 needed, from the list taped to the wall above the table:

- [x] add up the constituents correctly (October)
- [x] the nodal corrections, the 18.6-year wobble of the moon's orbit, which I got wrong twice
- [x] find high and low waters from the curve, not just heights
- [x] read constituents from the two common file formats
- [x] check against a year of real tables for three ports, Whitby first
- [x] tests for all of it
- [x] the README
- [ ] a logo (never)

The README was the hardest. I wrote it four times, and the fourth version opens with the warning in capitals.

::file[The README as it shipped with 1.0]{file="tideline-readme" title="tideline README"}

1.0 went out on 2 April 2018, Easter Monday, at about eleven at night. I emailed Dad a screenshot of Whitby's tides for the week. He replied the next morning: "Matches the book."
